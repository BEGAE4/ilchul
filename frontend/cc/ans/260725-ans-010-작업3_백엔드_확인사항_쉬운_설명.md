## 먼저, 작업 3이 무슨 기능인가요?

이미 만들어 둔 여행 코스에서 **① 장소 순서를 바꾸거나 추가/삭제하는 편집 기능**과, 그 장소에 실제로 방문했다는 **② 방문 인증(도장 찍기) 기능**입니다.

이 두 기능이 지금 **백엔드에 물어봐야만 마무리할 수 있는 상태**라 잠시 멈춰둔 것이고, 나머지(댓글·플랜·신고 등)는 이미 다 반영했습니다.

## 확인 1. "출발지"를 몰라서 코스 편집을 못 하는 문제

### 쉬운 비유
택배 기사님이 배송 순서를 다시 짜려면 **"어디서 출발하는지(집·허브 주소)"**를 반드시 알아야 합니다. 그런데 지금 시스템은 코스를 불러올 때 그 **출발지 주소를 알려주지 않습니다.** 그래서 순서를 다시 짜서 저장하려는 순간, 출발지를 비워둔 채 보내게 됩니다.

### 지금 상황
- 사용자가 코스의 장소 순서를 바꾸면, 앱은 서버에 **"이 코스의 출발지 + 새 장소 순서"**를 같이 보내야 합니다. (서버 규칙상 출발지가 필수 항목)
- 그런데 앱이 코스 상세를 불러올 때 **출발지 정보가 응답에 들어있지 않습니다.** 즉 앱은 "원래 출발지가 어디였는지"를 알 방법이 아예 없습니다.

### 이대로 두면 생기는 위험 (둘 중 하나)
- **(A) 저장이 거부됨** — 서버가 "출발지는 필수인데 비어 있네" 하고 에러를 내면, 순서 변경 저장 자체가 안 됩니다.
- **(B) 원래 출발지가 지워짐** — 서버가 빈 값을 그대로 받아서 "출발지 없음"으로 덮어쓰면, 잘 있던 출발지가 사라집니다. (데이터가 망가지는 더 나쁜 경우)

### 백엔드에 물어볼 것
1. 출발지를 **안 보내고** 코스 수정 요청을 하면, 서버는 **기존 출발지를 그대로 유지**하나요, 아니면 **비워버리나요?**
2. 코스 상세 조회(플랜 상세) 응답에 **출발지 정보를 넣어줄 수 있나요?** → 그러면 앱이 그 값을 받아서 수정할 때 다시 돌려보낼 수 있어 문제가 깔끔히 풀립니다.
3. (참고) 수정 전 미리보기를 요청할 때 출발지를 생략하면, 미리보기 응답에 **저장돼 있던 출발지를 채워서 돌려주나요?**

### 답변에 따른 처리
- "상세 응답에 출발지를 넣어주겠다" → 앱이 그 값을 받아서 그대로 재전송 (가장 깔끔).
- "출발지를 생략하면 서버가 알아서 기존 값을 유지한다" → 앱은 출발지를 비워 보내도 안전.
- "출발지는 무조건 필수" + "상세에도 안 준다" → 이 경우 앱이 출발지를 알 방법이 없어, 백엔드 지원 없이는 이 기능을 완성할 수 없습니다.

## 확인 2. "위치 없이도 방문 인증(도장)이 되는가?" 문제

### 쉬운 비유
스탬프 투어에서 "여기 진짜 왔다"를 증명하려면 보통 **사진 + 지금 있는 위치(GPS)**를 함께 제출합니다. 그런데 사용자가 폰에서 위치 접근을 거부하면, 앱은 **위치 없이 사진만** 제출하게 됩니다.

### 지금 상황
- 방문 인증은 **사진 + 현재 위치**를 서버로 보냅니다.
- 사용자가 위치 권한을 막으면, 앱은 지금 위치 정보를 뺀 채로 인증을 보냅니다.

### 백엔드에 물어볼 것
- 위치 정보가 **빠진 인증 요청**이 오면 서버는 어떻게 처리하나요?
  - **위치가 필수라 거부(에러)** → 그렇다면 앱에서 미리 "위치 권한을 켜주세요" 하고 **막아야** 합니다. (위치 끈 사용자는 인증 불가)
  - **위치 없어도 통과** → 그러면 위치 확인 없이 도장이 찍히는데, **그래도 괜찮은가요?** (실제로 안 가고도 인증하는 부정 사용 우려가 있어, 기획 확인도 필요)

### 답변에 따른 처리
- "위치 필수" → 앱에 "위치 권한 필요" 안내를 넣고, 위치 없으면 인증을 막습니다.
- "위치 선택(없어도 됨)" → 지금처럼 두되, 위치 없는 인증을 서버가 어떻게 신뢰하는지 기획과 함께 정리합니다.

## 백엔드 팀에 그대로 보낼 수 있는 질문 정리

1. 코스 장소 수정 시 **출발지를 생략하면** 기존 출발지가 유지되나요, 삭제되나요?
2. **플랜(코스) 상세 조회 응답에 출발지 정보를 포함**해 줄 수 있나요?
3. 수정 미리보기에서 출발지를 생략하면, **응답에 기존 출발지를 채워** 주나요?
4. 방문 인증(스탬프)에서 **위치 정보가 없으면** 거부하나요, 통과시키나요?
5. (참고) 코스 총 이동 거리 값의 **단위는 미터인가요, 킬로미터인가요?**
