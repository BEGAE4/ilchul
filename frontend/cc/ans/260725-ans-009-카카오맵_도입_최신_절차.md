## ⚠️ 핵심 변경: 2026년 7월 21일부터 카카오맵 API 운영 방식 개편

이번 주(2026-07-21)에 적용된 공식 변경사항이라 반드시 반영해야 한다.

1. **활성화 방식 변경**: 기존 "추가 기능 신청 → 관리자 심사" 절차 폐지. 앱 관리 페이지에서 **[카카오맵] > [사용 설정] ON**으로 직접 활성화.
2. **무료 쿼터 제공 방식 변경**: 개발자 계정 기준 **첫 번째로 카카오맵 API를 활성화한 앱에만 무료 쿼터 제공**. 두 번째 활성화 앱부터는 비즈월렛 연결 + 유료 API 사용 설정 필요. (앱 정보에 "[카카오맵 무료 쿼터]" 뱃지로 확인 가능)
   - → **팀 프로젝트 주의**: 개인 계정마다 테스트 앱을 만들지 말고, **팀 공용 카카오 계정 1개로 앱을 만들어 공유**하는 것이 안전하다. 무료 쿼터가 계정당 1앱이므로 앱 키를 팀에서 공유해 사용할 것.
3. **신규 오픈 API 4종 추가**: 대중교통 경로 조회 / 도보 경로 조회 / 자전거 경로 조회 / 정적 지도 조회.
   - → 기존 검토(ans-008 ⑥)에서 "실경로는 Kakao Mobility 별도 신청 필요"라고 했으나, **이제 카카오맵 API 안에서 경로 조회가 가능**해져 별도 Mobility 계약 없이 쓸 수 있다 (단 무료 쿼터가 일 1,000건으로 작음).

## 1. Kakao Developers 앱 설정 (2026년 최신 절차)

1. [developers.kakao.com](https://developers.kakao.com) 로그인 → **[내 애플리케이션] > 앱 생성**
2. 앱 관리 페이지 → **[카카오맵] > [사용 설정] ON** (필수 — 켜지 않으면 지도 SDK 호출이 거부됨)
3. **[앱 설정] > [앱] > [플랫폼 키]**에서 키 확인:
   - **JavaScript 키** → 지도 Web SDK(`dapi.kakao.com/v2/maps/sdk.js`)의 `appkey`
   - **REST API 키** → 로컬 REST API(주소↔좌표 변환, 키워드 장소 검색), 경로 조회 API 서버 호출용
4. JavaScript 키 선택 → **"JavaScript SDK 도메인" 등록** (구 "웹 플랫폼 도메인" 등록에 해당):
   - `http://localhost:3000`
   - `https://il-chul.com`
   - 도메인은 여러 개 등록 가능. 등록되지 않은 도메인에서는 SDK 로드가 차단된다.

## 2. 무료 쿼터 / 요금 (공식 쿼터 문서 기준)

| API | 무료 쿼터 | 초과 시 단가 |
|-----|----------|-------------|
| 전체 API 합산 | 월 3,000,000건 | — |
| 지도 Web(JavaScript) SDK | 일 300,000건 | 0.1원/건 |
| 주소로 좌표 변환 / 좌표로 주소 변환 | 각 일 100,000건 | 0.5원/건 |
| 키워드로 장소 검색 / 카테고리로 장소 검색 | 각 일 100,000건 | 2원/건 |
| 대중교통·도보·자전거 경로 조회 | 각 일 1,000건 | 10원/건 |
| 정적 지도 조회 | 일 1,000건 | 2원/건 |

- 무료 쿼터 초과 사용은 비즈월렛 연결 + 유료 API 사용 설정을 해야만 가능 (설정 안 하면 한도 초과 시 호출 실패로 끝나고 과금은 안 됨).
- 일출 규모(공모전/팀 프로젝트)에서는 일 30만 건의 지도 SDK 쿼터를 초과할 가능성이 사실상 없음.

## 3. 환경변수

`.env.local`에 추가 (JS 키는 브라우저에 노출되는 전제의 키 — 도메인 제한으로 보호되므로 `NEXT_PUBLIC_` 접두사 사용이 표준):

```bash
NEXT_PUBLIC_KAKAO_MAP_APP_KEY=발급받은_JavaScript_키
```

REST API 키는 브라우저에 노출하면 안 되므로, 로컬 REST API를 쓸 경우 Next.js API 라우트(BFF)나 백엔드에서 호출하고 `KAKAO_REST_API_KEY`(NEXT_PUBLIC_ 없이)로 보관.

## 4. react-kakao-maps-sdk 설치 및 설정

- 최신 버전 **1.2.1** — peerDependencies가 `react ^16.8 || ^17 || ^18 || ^19`로 **React 19 공식 지원** → 이 프로젝트(React 19 + Next 15.3.5) 호환 확인됨.

```bash
yarn add react-kakao-maps-sdk
```

### App Router 권장 방식: `useKakaoLoader` 훅

```tsx
// src/shared/lib/hooks/useKakaoMapLoader.ts
'use client';

import { useKakaoLoader } from 'react-kakao-maps-sdk';

export function useKakaoMapLoader() {
  return useKakaoLoader({
    appkey: process.env.NEXT_PUBLIC_KAKAO_MAP_APP_KEY!,
    libraries: ['services', 'clusterer'], // services: 주소 변환·장소 검색(Geocoder/Places)
  });
}
```

```tsx
// 사용 예 — 지도를 쓰는 컴포넌트는 반드시 'use client'
'use client';

import { Map, MapMarker, Polyline } from 'react-kakao-maps-sdk';
import { useKakaoMapLoader } from '@/shared/lib/hooks/useKakaoMapLoader';

export function RouteMap({ stops }: { stops: { name: string; lat: number; lng: number }[] }) {
  const [loading, error] = useKakaoMapLoader();
  if (loading) return <div>지도 로딩 중…</div>;
  if (error) return <div>지도를 불러오지 못했습니다</div>;

  return (
    <Map center={{ lat: stops[0].lat, lng: stops[0].lng }} style={{ width: '100%', height: 200 }}>
      {stops.map((s, i) => (
        <MapMarker key={i} position={{ lat: s.lat, lng: s.lng }} />
      ))}
      <Polyline path={stops.map((s) => ({ lat: s.lat, lng: s.lng }))} strokeColor="#f97316" />
    </Map>
  );
}
```

### 대안: `next/script` 직접 로드 (레이아웃에 1회)

```tsx
<Script
  strategy="beforeInteractive"
  src={`//dapi.kakao.com/v2/maps/sdk.js?appkey=${process.env.NEXT_PUBLIC_KAKAO_MAP_APP_KEY}&libraries=services,clusterer&autoload=false`}
/>
```

`autoload=false` 후 `kakao.maps.load(callback)`으로 초기화. useKakaoLoader를 쓰면 이 과정이 자동 처리되므로 훅 방식을 권장.

### TypeScript 설정

`tsconfig.json`에 카카오맵 타입 추가 (react-kakao-maps-sdk가 `kakao.maps.d.ts`를 의존성으로 포함):

```json
{
  "compilerOptions": {
    "types": ["kakao.maps.d.ts"]
  }
}
```

## 5. 일출 적용 시 참고 (ans-008 연계)

| ans-008 항목 | 이 문서 기준 최신 방법 |
|--------------|----------------------|
| ① RouteMap 교체 | `Map` + `MapMarker` + `Polyline` (JS SDK, 일 30만 건 무료) |
| ② 출발지 역지오코딩·주소 검색 | JS SDK `libraries=services`의 `Geocoder.coord2Address()` / `Places.keywordSearch()`로 **프론트에서 REST 키 없이 처리 가능**. REST API를 쓸 경우만 백엔드 경유 |
| ⑥ 실경로 표시 | **신규 도보/대중교통 경로 조회 API 사용 가능** (2026-07-21 신설, 일 1,000건 무료 — 서버에서 REST 키로 호출). 소요시간·거리는 여전히 v6 `plan-place/preview` 서버 값 우선 |
