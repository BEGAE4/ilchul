## 1. 필수 적용 지점 (현재 mock/가짜로 동작하는 곳)

### ① 코스 작성 — RouteMap (가짜 SVG 지도) → 실지도 교체

- 파일: `src/features/course-creation/components/RouteMap.tsx`
- 격자 + "도로 느낌 선"을 SVG로 그린 플레이스홀더. 좌표도 `PLACE_COORDS`(mock, `src/shared/data/mockData.ts:634`) 기반.
- `CourseCreationFlow.tsx`에서 3곳 사용:
  - `:910` 출발지 선택 화면 지도 프리뷰
  - `:1077` 경로 미리보기 단계
  - `:1326` 최종 플랜 확인 화면 (마커 + 경로선)
- **적용**: Kakao Maps JS SDK 지도 + 마커(순번 라벨) + Polyline으로 교체. 좌표는 mock 대신 v6 API(`place.x/y`, `plan-place/preview`의 `x/y`)에서 공급.
- 주의: `PLACE_COORDS`는 문자열 id 키인데 서버 장소는 숫자 `placeId` — 교체 시 mock 좌표 의존 제거 필요.

### ② 코스 작성 — 출발지 선택 (역지오코딩/주소 검색 mock)

- 파일: `src/features/course-creation/components/CourseCreationFlow.tsx` (step `'startPoint'`)
- 현재 문제 3가지:
  1. **"현재 위치로 설정"** (`:936~`): GPS 좌표는 실제로 받지만 주소는 `'서울 용산구 한강대로 405 서울역'` **하드코딩** → Kakao Local REST API `coord2address`(좌표→주소 역지오코딩) 필요
  2. **주소 검색**: `MOCK_ADDRESSES` 배열을 클라이언트에서 필터링(`:884`, `:1030`) → Kakao Local `keyword.json`/`address.json` 검색 필요 (프론트 직접 호출 또는 백엔드 경유)
  3. 안내 문구가 "지도에서 출발지를 선택하거나 검색해주세요"(`:894`)인데 **지도 탭 선택 기능 미구현** → SDK 지도 클릭 → `coord2address`로 주소 확정 흐름 필요
- 확정된 출발지는 v6 `departurePoint { name, address, x, y }`로 전송되므로 API 계약은 이미 준비됨.

### ③ 장소 상세 — 길찾기 링크 파라미터 버그

- 파일: `src/features/place-detail/components/PlaceDetailPage.tsx:329`
- 현재: `map.kakao.com/link/to/${place.name},${place.location}` — `link/to`의 올바른 형식은 `이름,위도,경도`인데 **주소 문자열**을 넣고 있어 정상 동작하지 않음.
- **수정**: 서버 장소의 `y,x`(위도,경도)로 교체 — `map.kakao.com/link/to/${name},${y},${x}`. SDK 없이도 고칠 수 있는 버그지만 카카오맵 연동 작업 범위에 포함할 것.

## 2. 권장 적용 지점 (SDK 도입 시 함께)

### ④ 장소 상세 — 인라인 위치 지도

- 파일: `src/features/place-detail/components/PlaceDetailPage.tsx:372~390` (주소 섹션)
- 현재는 `placeUrl` 또는 `map.kakao.com/link/search/` 외부 링크만 제공. v6 장소 상세가 `x, y`를 주므로 주소 섹션에 미니맵(정적 수준, 드래그 비활성) 삽입 가능.

### ⑤ 코스 상세 / 내 코스 — 경로 지도

- 파일: `src/features/course-detail/components/CourseViewPage.tsx`, `src/features/search/components/CourseDetailPage.tsx`, `src/features/my-course/components/MyCourseDetailPage.tsx`
- 현재 타임라인 리스트만 있고 지도가 전혀 없음. 플랜 장소 좌표(v6 `plan-place/preview` 응답 `x, y`)로 전체 경로 지도 제공 가능.
- `MyCourseDetailPage`는 방문 인증 스탬프 시 현재 위치(`getCurrentLocation`, `:90~`)를 이미 수집하므로, 지도에 "내 위치 ↔ 장소" 거리를 시각화하면 422(거리 멀음) UX 개선에 활용 가능.

### ⑥ 이동 시간/거리 계산 대체

- 파일: `src/features/course-creation/components/CourseCreationFlow.tsx:408` `getTravelMinutes`
- 현재 유클리드 거리 × 500 + 5분의 임시 계산. **1차 대체재는 카카오가 아니라 v6 `POST /api/plan-place/preview`** (서버가 `requiredTime`, `totalDistance`, 구간별 `duration` 반환).
- 참고: Kakao Maps JS SDK에는 길찾기(경로 탐색) API가 없음 — 실경로 폴리라인이 필요하면 **Kakao Mobility 길찾기 REST API**(별도 신청) 대상. 공모전 단계에서는 서버 preview 값 + 직선 폴리라인으로 충분.

## 3. 적용 불필요 / 제외

| 위치 | 사유 |
|------|------|
| 홈 내 주변 인기 플랜/장소 (`useGeolocation`, `/api/plan/popular?lat&lng`) | 좌표를 쿼리로 보낼 뿐 지도 UI 없음 |
| 피드 `/map` 라우트 (`FeedDetailPage.tsx:27`) | 피드는 비활성화 기능. 실제로 `src/app/map` 라우트 자체가 없음 |
| 카카오 로그인 / 카카오톡 공유 | 지도와 무관 — [[260725-ans-007]] 검토 참조 |

## 4. 도입 준비물 체크리스트

1. **Kakao Developers 앱 등록**: JavaScript 키(지도 SDK용) + REST API 키(Local API용), 플랫폼 도메인 등록(`http://localhost:3000`, `https://il-chul.com`)
2. **환경변수**: `NEXT_PUBLIC_KAKAO_MAP_APP_KEY` 추가 (JS 키는 브라우저 노출 전제 — 도메인 제한으로 보호)
3. **라이브러리**: `react-kakao-maps-sdk` 권장 (또는 `next/script`로 SDK 직접 로드 + autoload=false)
4. 지도/로컬 API는 **사업자 인증 없이 사용 가능** (일반 앱 무료 쿼터). 단, 카카오맵 API 쿼터/과금 정책은 최근 변동이 있었으므로 신청 시점에 콘솔에서 재확인할 것
5. Local REST API를 프론트에서 직접 호출할지, 백엔드 프록시로 둘지 백엔드와 합의 필요 (REST 키는 서버 보관이 원칙)
