## 전체 미연동(❌) 요약

1. **고객 문의 관리자 API 전체** — `/api/cs-inquiry`, `/api/cs-inquiry/{id}/reply` 등 swagger 정의 경로가 프론트의 `/api/admin/inquiries` BFF와 경로 체계 자체가 달라 실질적으로 미연동. `admin-inquiry` 기능은 완전 목데이터.
2. **댓글 수정 PATCH `/api/reply/{replyId}`** — v5 신규 API, 프론트에 수정 UI/함수 없음.
3. **메인 홈 인기 플랜/장소 4종** — BFF 프록시 코드는 있으나 `NEXT_PUBLIC_API_BASE_URL` 미설정 시 목데이터 폴백 (배포 환경 설정 확인 필요).

## 우선순위 제안

1. 고객 문의 관리자 기능을 swagger `cs-inquiry` 경로 체계로 재정렬할지, 현재 `admin/inquiries` BFF 목을 유지할지 백엔드와 경로 합의 필요.
2. 댓글 수정 UI 구현 여부 결정 (기획 확정 시 PATCH 연동).
3. 메인 홈 4개 API의 `NEXT_PUBLIC_API_BASE_URL` 배포 설정 확인 — 로컬은 목데이터로만 동작 중이라 실제 v5 연동 여부를 별도로 검증해야 함.

## 2026-07-20 추가 연동 작업

아래 3개 항목을 실제 API 연동으로 전환함 (커밋 전, 로컬 lint/tsc 통과 확인):

1. **장소 검색** — `src/features/search/components/SearchResultsPage.tsx`
   - 검색어(`query`)가 있을 때 `searchPlaces(query)`(`@/features/place/api/place.api`)를 호출해 `장소` 탭/`전체` 탭의 장소 목록을 채움
   - `SearchPlaceItem` → `BestPlace` 매핑 함수(`mapSearchPlaceItemToBestPlace`) 추가. 서버가 `location`(주소 문자열)·`likes`를 내려주지 않아 각각 빈 문자열/0으로 채움 — 추후 서버 필드 확정 시 보완 필요
   - 플랜/코스 검색은 서버에 대응 API가 없어 기존 로컬 목데이터 필터링 유지

2. **장소 추천** — `src/features/course-creation/components/CourseCreationFlow.tsx`
   - 설문(`survey1~3`, 출발지) 완료 후 `startPoint → generating` 전환 시 `recommendPlaces(SurveyResult)`(`@/features/place/api/place.api`) 호출
   - 응답 스키마가 서버에서 미확정 상태이므로 `mapRecommendedPlaces`로 방어적 파싱(배열이 아니거나 필드가 없으면 무시) 후, 결과가 있으면 `recommendedPlaces` 상태로 교체, 실패/빈 배열이면 기존 `RECOMMENDED_PLACES` 목데이터를 그대로 사용
   - 로딩 화면(`generating`)은 API 응답과 최소 1.5초 중 더 긴 쪽을 기다려 UX 유지
   - **후속 확인 필요**: 실제 서버 응답 스키마가 확정되면 `mapRecommendedPlaces`의 필드 매핑(`placeId`/`placeName`/`categoryName`/`placeImageUrl` 등 가정)을 재검증할 것

3. **마이페이지 저장 플랜 목록** — `src/features/profile/components/ProfilePage.tsx`
   - '저장 플랜' 탭이 기존 로컬 목데이터(`useCourseStore.getBookmarkedCourses`) 대신 `planApi.fetchMyScraps()`(`GET /api/mypage/scrapped`, apiClient 직접 호출)를 사용하도록 변경
   - 사용하지 않게 된 `toggleBookmark`/`bookmarkedIds`/`getBookmarkedCourses` 및 관련 아이콘 import 정리
   - 참고: '내 플랜' 탭(`GET /api/mypage/plans`)은 이미 `my-page/api`를 통해 연동되어 있었음 (BFF 경유)
