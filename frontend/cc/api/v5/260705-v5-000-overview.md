## v4 대비 주요 변경점 (플랜 도메인 중심)

| 항목 | v4 | v5 |
| --- | --- | --- |
| 플랜 생성 | `POST /api/plan` (title, description, isPublic, thumbnailUrl) | `POST /api/plan/create` (planTitle, isPlanVisible, planDescription, departurePoint, tripStartDate/EndDate, places 포함 — 생성 시 장소까지 일괄 등록) |
| 플랜 수정 | `PUT /api/plan/{planId}` | `PATCH /api/plan/{planId}` (planTitle, isPlanVisible, planDescription, tripStartDate/EndDate) |
| 플랜 좋아요 | `POST/DELETE /api/plan/{planId}/like` | `POST/DELETE /api/like/{planId}` (응답: `{ isLiked, likeCount }`) |
| 플랜 스크랩 | `POST/DELETE /api/plan/{planId}/scrap` | `POST /api/plan/scrapped/{planId}` (토글형, DELETE 없음) |
| 공개 설정 | `PATCH /api/plan/{planId}/visibility` + body | `POST /api/mypage/plan/visibility/{planId}` (body 없음, 토글형) |
| 내 플랜 목록 | `GET /api/plan/my` | `GET /api/mypage/plans` |
| 내 스크랩 목록 | `GET /api/plan/my/scrap` | `GET /api/mypage/scrapped` |
| 플랜 상세 응답 | `{ status, data: {...} }` 래핑 | `PlanDetailDto` 직접 반환 (필드명도 상이: planTitle, isPlanVisible, isBookmarked, planPlaceDetailDtos 등) |
| 신규 | — | 플랜 이미지 업로드/삭제, 플랜 복제(clone), 플랜 생성/수정 프리뷰, 스탬프 인증, 장소 후기/좋아요/스크랩, 고객 문의(cs-inquiry) |

## 공통 사항

- 모든 응답 `content-type`: `*/*` (JSON)
- ID 타입: `integer(int32)`
- 날짜: `date-time` (ISO 8601)
- 커서 페이징: `lastXxxId` + `size`(또는 `limit`) 쿼리, 응답에 `hasNext` 포함
- 오프셋 페이징(인기 목록, 관리자): `page` + `limit`(또는 `size`), 응답에 `totalCount`, `hasNext` 포함
- 인증 실패 시 진입점: `GET /api/exception/entry-point`(401), `GET /api/exception/access-denied`(403)
