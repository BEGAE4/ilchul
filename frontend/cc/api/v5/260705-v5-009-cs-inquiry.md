# CS-INQUIRY(고객 문의) API (v5)

> 원본: [api-docs.json](api-docs.json) — 태그 `고객 문의` (v5 신규 도메인)

## 공통 enum

| enum | 값 |
| --- | --- |
| inquiryType | `GENERAL`, `BUG`, `SUGGESTION`, `OTHER` |
| inquiryStatus | `OPEN`, `IN_PROGRESS`, `RESOLVED`, `CLOSED` |

## 엔드포인트

| 제목 | 메서드 | URL | 권한 | 응답 |
| --- | --- | --- | --- | --- |
| 문의 작성 | POST | `/api/cs-inquiry` | 사용자 | 201, `CreateCsInquiryResponseDto` |
| 내 문의 목록 조회 | GET | `/api/cs-inquiry/my` | 사용자 | `UserCsInquiryListResponseDto` |
| 문의 카테고리 목록 | GET | `/api/cs-inquiry/category` | 공용 | `InquiryTypeListResponseDto` |
| 문의 수정 | PATCH | `/api/cs-inquiry/{inquiryId}` | 작성자 | `UpdateCsInquiryResponseDto` |
| 문의 삭제 | DELETE | `/api/cs-inquiry/{inquiryId}` | 작성자 | 200 |
| 문의 종료(완료) | PATCH | `/api/cs-inquiry/{inquiryId}/close` | 작성자 | 200 |
| 문의 목록 조회 | GET | `/api/cs-inquiry` | 관리자 | `AdminCsInquiryListResponseDto` |
| 문의 답변 작성 | POST | `/api/cs-inquiry/{inquiryId}/reply` | 관리자 | `ReplyCsInquiryResponseDto` |

---

## 1. 문의 작성 — POST `/api/cs-inquiry`

### 요청 (`CreateCsInquiryRequestDto`) — ⚠️ 문서상 query 파라미터로 정의됨 (이미지 포함이므로 실제로는 multipart 추정, 서버 확인 필요)

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| title | String | 필수(minLength 1) | 제목 |
| content | String | 필수(minLength 1) | 내용 |
| inquiryType | enum | 필수 | 문의 카테고리 |
| images | binary[] | 선택 | 첨부 이미지 |

### 응답 (201, `CreateCsInquiryResponseDto`)

```json
{
  "inquiryId": 3,
  "title": "앱이 자꾸 꺼져요",
  "inquiryType": "BUG",
  "inquiryStatus": "OPEN",
  "createdAt": "2026-07-05T10:00:00"
}
```

---

## 2. 내 문의 목록 — GET `/api/cs-inquiry/my` (커서 페이징)

### 쿼리: `size`(기본 10), `lastInquiryId`(커서)

### 응답 (`UserCsInquiryListResponseDto`)

```json
{
  "items": [
    {
      "inquiryId": 3,
      "title": "앱이 자꾸 꺼져요",
      "inquiryType": "BUG",
      "inquiryStatus": "IN_PROGRESS",
      "hasAnswer": true,
      "createdAt": "2026-07-05T10:00:00"
    }
  ],
  "nextCursorId": 3,
  "hasNext": false
}
```

---

## 3. 카테고리 목록 — GET `/api/cs-inquiry/category`

```json
{ "categories": [{ "slug": "BUG", "name": "버그 신고" }] }
```

---

## 4. 문의 수정 — PATCH `/api/cs-inquiry/{inquiryId}`

### 요청 (`UpdateCsInquiryRequestDto`) — ⚠️ 작성과 동일하게 query로 정의됨

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| title / content | String | 필수 | 제목/내용 |
| inquiryType | enum | 필수 | 카테고리 |
| newImages | binary[] | 선택 | 추가 이미지 |
| deleteImageIds | Integer[] | 선택 | 삭제할 이미지 ID |

### 응답 (`UpdateCsInquiryResponseDto`): `{ inquiryId, title, content, inquiryType, inquiryStatus, updatedAt }`

---

## 5. 관리자 — 문의 목록 조회 — GET `/api/cs-inquiry`

### 쿼리: `category`(enum), `search`(제목/내용 키워드), `size`(기본 10), `lastInquiryId`(커서)

### 응답 (`AdminCsInquiryListResponseDto`)

내 문의 목록 항목 + `authorNickname`, 그리고 `totalCount`(int64) 포함.

---

## 6. 관리자 — 답변 작성 — POST `/api/cs-inquiry/{inquiryId}/reply`

### 요청 (`ReplyCsInquiryRequestDto`): `{ "content": "..." }` (minLength 1)

### 응답 (`ReplyCsInquiryResponseDto`)

```json
{
  "answerId": 1,
  "inquiryId": 3,
  "content": "확인 후 수정했습니다.",
  "answeredBy": "admin1",
  "answeredAt": "2026-07-05T11:00:00"
}
```
