# COMMENT(댓글) API (v5)

> 원본: [api-docs.json](api-docs.json) — 태그 `댓글`

| 제목 | 메서드 | URL | 응답 |
| --- | --- | --- | --- |
| 플랜 댓글 목록 조회 | GET | `/api/reply/{planId}` | 200, `ReplyListResponse` |
| 댓글 작성 | POST | `/api/reply/{planId}` | 201, 생성된 댓글 ID(Integer) |
| 대댓글 목록 조회 | GET | `/api/reply/{parentReplyId}/children` | 200, `ReplyListResponse` |
| 댓글 수정 | PATCH | `/api/reply/{replyId}` | 200, 수정된 댓글 ID(Integer) |
| 댓글 삭제 | DELETE | `/api/reply/{replyId}` | 200, 삭제된 댓글 ID(Integer) |
| 댓글 좋아요 | POST | `/api/reply/like/{replyId}` | 200, Integer |
| 댓글 좋아요 취소 | DELETE | `/api/reply/like/{replyId}` | 200, Integer |

---

## 1. 댓글 / 대댓글 목록 조회 (커서 페이징, 비로그인 가능)

### 쿼리 파라미터

| 이름 | 필수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| size | 선택 | 10 | 페이지 크기 |
| lastReplyId | 선택 | - | 마지막 조회 댓글 ID (커서) |

### 응답 (`ReplyListResponse`)

```json
{
  "replies": [
    {
      "replyId": 100,
      "parentReplyId": null,
      "user": "힙스터김",
      "userId": 4,
      "avatar": "https://example.com/profile.jpg",
      "content": "좋은 플랜이네요! @여행러버",
      "mentions": [{ "userId": 7, "userNickname": "여행러버" }],
      "createdAt": "2026-07-01T10:00:00",
      "likeCount": 3,
      "isLiked": false,
      "replyCount": 2,
      "isDeleted": false,
      "replies": { "replies": [], "hasNext": false }
    }
  ],
  "hasNext": true
}
```

> v4 대비: `mentions`(멘션 사용자 배열), `isDeleted`, 중첩 `replies`(재귀 `ReplyListResponse`) 필드 추가. 댓글 수정(PATCH)도 신규.

## 2. 댓글 작성 — POST `/api/reply/{planId}`

### 요청 본문 (`CreateReplyRequestDto`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| content | String | 댓글 내용 |
| parentReplyId | Integer | 부모 댓글 ID (대댓글일 때만) |
| mentions | Integer[] | 멘션할 userId 목록 |

- 응답: 201, 생성된 댓글 ID (Integer 단일 값)

## 3. 댓글 수정 — PATCH `/api/reply/{replyId}`

### 요청 본문 (`PatchReplyRequestDto`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| content | String | 수정할 내용 |
| mentions | Integer[] | 멘션할 userId 목록 |

- 응답: 200, 수정된 댓글 ID

## 4. 댓글 삭제 / 좋아요

- 삭제: `DELETE /api/reply/{replyId}` → 삭제된 댓글 ID 반환
- 좋아요 등록/취소: `POST` / `DELETE /api/reply/like/{replyId}` → Integer 반환 (좋아요 수로 추정 — v4는 `{ likeCount, isLiked }` 객체였음, 서버 확인 필요)
