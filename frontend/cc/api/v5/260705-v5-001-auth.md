# AUTH API (v5)

> 원본: [api-docs.json](api-docs.json) — `sign-controller`, `exception-controller`

| 제목 | 메서드 | URL | 응답 |
| --- | --- | --- | --- |
| 로그아웃 | POST | `/api/sign/logout` | 200 |
| 사용자 정보 조회 | GET | `/api/sign/userinfo` | 200, `object` |
| 토큰 재발급 | GET | `/api/sign/reissue` | 200, `string` (새 토큰) |
| 회원 탈퇴 | DELETE | `/api/sign/delete` | 200 |
| 인증 예외 진입점 | GET | `/api/exception/entry-point` | 200 (401 처리용 내부 엔드포인트) |
| 접근 거부 예외 | GET | `/api/exception/access-denied` | 200 (403 처리용 내부 엔드포인트) |

## 인증 방식

- JWT Bearer 토큰 (`Authorization: Bearer {token}`)
- 보안 스킴명: `jwtAuth` (http / bearer / JWT)
- 문서 전체에 기본 적용 (`security: [{ jwtAuth: [] }]`)

## 비고

- 로그인/회원가입 엔드포인트는 이 문서에 노출되지 않음 (소셜 로그인 등 별도 플로우로 추정)
- `userinfo` 응답 스키마는 `object`로만 정의되어 있어 실제 필드는 서버 확인 필요
