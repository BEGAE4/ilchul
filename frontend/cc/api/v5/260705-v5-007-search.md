| 제목 | 메서드 | URL | 응답 |
| --- | --- | --- | --- |
| 최근 검색어 목록 조회 | GET | `/api/recent` | 200, `SearchLog[]` |
| 최근 검색어 추가 | POST | `/api/recent` | 200 |
| 최근 검색어 삭제 | DELETE | `/api/recent` | 200 |

## 1. 최근 검색어 목록 조회

### 응답 (`SearchLog[]`)

```json
[
  { "name": "성수 카페", "createdAt": "2026-07-05T10:00:00" }
]
```

## 2. 최근 검색어 추가 — POST `/api/recent`

### 요청 본문 (`SearchLogSaveRequest`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| name | String | 검색어 |

## 3. 최근 검색어 삭제 — DELETE `/api/recent`

### 요청 본문 (`SearchLogDeleteRequest`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| name | String | 삭제할 검색어 |
| createdAt | String | 해당 검색어의 생성 시각 (동일 검색어 구분용) |
