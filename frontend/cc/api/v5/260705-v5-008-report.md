# REPORT(신고) API (v5)

> 원본: [api-docs.json](api-docs.json) — `report-controller`, `report-admin-controller`

## 공통 enum

| enum | 값 |
| --- | --- |
| targetType / reportType | `PLAN`, `REPLY`, `USER` |
| reasonCode | `SPAM_AD`, `FAKE_INFO`, `OBSCENE`, `ABUSE`, `COPYRIGHT`, `IMPROPER_PROFILE`, `IMPERSONATION`, `PERSONAL_INFO_LEAK`, `ETC` |
| status | `PENDING`, `REVIEWING`, `RESOLVED`, `REJECTED` |
| resolution | `BLINDED`, `WARNED`, `BANNED`, `NO_ACTION` |

---

## 사용자 신고

| 제목 | 메서드 | URL | 응답 |
| --- | --- | --- | --- |
| 신고 접수 | POST | `/api/report` | `CreateReportResponseDto` |
| 신고 사유 목록 조회 | GET | `/api/report/reason?type=` | `ReportReasonResponseDto` |

### 신고 접수 요청 (`CreateReportRequestDto`)

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| targetType | enum | 필수 | 신고 대상 타입 |
| targetId | Integer | 필수 | 대상 ID |
| reasonCode | enum | 필수 | 신고 사유 코드 |
| detail | String | 선택 | 상세 사유 |

### 신고 접수 응답 (`CreateReportResponseDto`)

```json
{
  "reportId": 5,
  "reportType": "PLAN",
  "status": "PENDING",
  "alreadyReported": false,
  "isAutoBlinded": false
}
```

### 신고 사유 목록 응답 (`ReportReasonResponseDto`)

```json
{
  "reportType": "PLAN",
  "reasonItems": [
    { "code": "SPAM_AD", "label": "스팸/광고", "requiresContent": false }
  ]
}
```

## 관리자 신고 관리

| 제목 | 메서드 | URL | 응답 |
| --- | --- | --- | --- |
| 신고 목록 조회 | GET | `/api/admin/reports` | `AdminReportResponseDto` |
| 신고 상세 조회 | GET | `/api/admin/reports/{reportId}` | `AdminReportDetailResponseDto` |
| 신고 상태 변경 | PATCH | `/api/admin/reports/{reportId}` | `AdminReportDetailResponseDto` |

### 목록 조회 쿼리 (`AdminReportRequestDto`)

| 이름 | 유형 | 제약 | 설명 |
| --- | --- | --- | --- |
| status / targetType / reasonCode | enum | 선택 | 필터 |
| q | String | 선택 | 검색 키워드 |
| page | Integer | ≥1 | 페이지 번호 |
| size | Integer | 1~100 | 페이지 크기 |
| sort | enum | 선택 | `CREATED_DESC`, `CREATED_ASC`, `REPORT_COUNT_DESC` |
| autoBlindedOnly | Boolean | 선택 | 자동 블라인드만 조회 |

### 상태 변경 요청 (`AdminReportStatusChangeRequestDto`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| status | enum | 변경할 상태 |
| note | String | 처리 메모 |

### 상세 응답 (`AdminReportDetailResponseDto`)

목록 항목 필드에 더해:

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| resolution | enum | 처리 결과 |
| detail | String | 신고 상세 사유 |
| histories | `History[]` | `{ status, at, actor, note }` 처리 이력 |
| relatedReports | `RelatedReport[]` | `{ reportId, reasonCode, reporterNickname, createdAt }` 동일 대상 관련 신고 |
