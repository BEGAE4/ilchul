# PLACE API (v5)

> 원본: [api-docs.json](api-docs.json) — 태그 `장소`

| 제목 | 메서드 | URL | 응답 스키마 |
| --- | --- | --- | --- |
| 장소 상세 조회 | GET | `/api/place/{placeId}` | `PlaceDetailResponseDto` |
| 장소 검색 | GET | `/api/place/search?keyword=` | `SearchPlaceResponseDto[]` |
| 내 주변 인기 장소 | GET | `/api/place/popular` | `PopularPlaceResponseDto` |
| 전국 인기 장소 | GET | `/api/place/popular/nationwide` | `PopularPlaceResponseDto` |
| 장소 추천 (설문 기반) | POST | `/api/place/recommend` | `object` |
| 장소 좋아요 등록 / 취소 | POST / DELETE | `/api/place/{placeId}/likes` | `LikeResponseDto` |
| 장소 스크랩 추가 / 취소 | POST / DELETE | `/api/place/{placeId}/scraps` | `ScrappedPlaceCreateResponseDto` |
| 장소 후기 목록 조회 | GET | `/api/place/{placeId}/review` | `PlaceReviewListResponseDto` |
| 장소 후기 작성 | POST | `/api/place/{placeId}/review` | 201, `PlaceReviewResponseDto` |
| 장소가 포함된 코스 조회 | GET | `/api/place/{placeId}/plan` | `PopularPlanItemDto[]` |

---

## 1. 장소 상세 조회

### 응답 (`PlaceDetailResponseDto`)

```json
{
  "placeId": 165,
  "placeName": "블루보틀 성수",
  "addressName": "서울 성동구 성수동1가",
  "roadAddressName": "서울 성동구 아차산로 17길 49",
  "categoryName": "카페",
  "phone": "02-1234-5678",
  "placeUrl": "http://place.map.kakao.com/...",
  "placeImageUrl": "https://example.com/cafe.jpg",
  "x": 127.0567,
  "y": 37.5447
}
```

## 2. 장소 검색

- 쿼리: `keyword` (필수, String)
- 응답: `SearchPlaceResponseDto[]` — `{ placeId, placeImageUrl, categoryName, placeName, x, y }`

## 3. 인기 장소 (내 주변 / 전국)

### 쿼리 파라미터

| 이름 | 필수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| lat / lng | 내 주변만 필수 | - | 위도/경도 (double) |
| limit | 선택 | 주변 5 / 전국 6 | 페이지 크기 |
| page | 선택 | 1 | 페이지 번호 |

### 응답 (`PopularPlaceResponseDto`)

```json
{
  "status": 200,
  "message": "success",
  "data": [
    { "id": 1, "name": "블루보틀 성수", "category": "카페", "location": "서울 성동구", "image": "...", "ranking": 1 }
  ],
  "page": 1,
  "limit": 5,
  "hasNext": true,
  "totalCount": 42
}
```

## 4. 장소 추천 (설문 기반)

### 요청 본문 (`SurveyResultDto`)

| 이름 | 유형 | 설명 |
| --- | --- | --- |
| emotion | String | 감정 상태 |
| startTime / endTime | String | 여행 시작/종료 시간 |
| transport | String | 이동 수단 |
| location | `{ x, y }` | 현재 위치 좌표 |

- 응답: `object` (스키마 미정의 — 서버 확인 필요)

## 5. 장소 좋아요 / 스크랩

- 좋아요 응답 (`LikeResponseDto`): `{ "isLiked": true, "likeCount": 24 }`
- 스크랩 응답 (`ScrappedPlaceCreateResponseDto`): `{ "placeId": 165, "isBookmarked": true, "bookmarkCount": 10 }`
- POST 등록 / DELETE 취소, 두 경우 모두 동일 응답 스키마

## 6. 장소 후기

### 목록 조회 쿼리 (커서 페이징)

| 이름 | 필수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| lastReviewId | 선택 | - | 마지막 조회 후기 ID |
| limit | 선택 | 10 | 페이지 크기 |

- 비로그인 사용자도 조회 가능

### 목록 응답 (`PlaceReviewListResponseDto`)

```json
{
  "status": 200,
  "message": "success",
  "data": [
    {
      "reviewId": 7,
      "userId": 4,
      "userNickname": "힙스터김",
      "userImg": "https://example.com/profile.jpg",
      "content": "분위기 최고!",
      "createAt": "2026-06-01T10:00:00"
    }
  ],
  "hasNext": false
}
```

### 작성 요청 (`PlaceReviewRequestDto`)

| 이름 | 유형 | 제약 | 설명 |
| --- | --- | --- | --- |
| content | String | 최대 1000자 | 후기 내용 |

- 응답: 201, `PlaceReviewResponseDto` (목록 항목과 동일 구조)

## 7. 장소가 포함된 코스 조회

- 특정 장소가 포함된 **공개** 코스 목록
- 응답: `PopularPlanItemDto[]` — `{ id, title, description, thumbnail, location, duration, likes, ranking }`
