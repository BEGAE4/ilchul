# MAIN-1. 내 주변 실시간 베스트 플랜 조회
## URL : GET /api/plan/popular

### 쿼리 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| lat | Float | 필수 | 현재 위치 위도 |
| lng | Float | 필수 | 현재 위치 경도 |
| limit | Integer | 선택 | 조회 개수 (기본 6) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 401 | 인증 필요 |
