# REP-1. 신고 사유 목록 조회
## URL : GET /api/report/reasons?type={reportType}

> 신고 다이얼로그 진입 시 신고 유형에 맞는 사유 목록을 가져온다.

### 쿼리 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| type | String | 필수 | 신고 대상 유형. `PLAN` / `COMMENT` / `USER` |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 400 | type 누락 또는 허용되지 않는 값 |
| 401 | 인증 필요 |

## 코드 예시

### 응답

```json
{
  "status": 200,
  "data": [
    { "code": "FAKE_INFO", "label": "허위 정보가 포함되어 있어요" },
    { "code": "SPAM_AD", "label": "광고/홍보성 내용이에요" },
    { "code": "INAPPROPRIATE", "label": "부적절한 내용이에요" },
    { "code": "COPYRIGHT", "label": "저작권을 침해해요" },
    { "code": "ETC", "label": "기타" }
  ]
}
```

# REP-2. 신고 제출
## URL : POST /api/reports

> `useReport` 훅에서 플랜(course) / 댓글(comment) / 사용자(user) 신고 모두 본 엔드포인트 단일 사용.
> BFF: `src/app/api/reports/route.ts`

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| targetType | String | 필수 | 신고 대상 유형. `PLAN` / `COMMENT` / `USER` |
| targetId | String | 필수 | 신고 대상 ID |
| reasonCode | String | 필수 | 신고 사유 코드 (REP-1 목록) |
| detail | String | 선택 | 상세 설명 (최대 500자, `ETC` 선택 시 권장) |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 신고 접수 성공 |
| 400 | 요청 데이터 오류 (targetType / reasonCode 누락) |
| 401 | 인증 필요 |
| 404 | 신고 대상을 찾을 수 없음 |
| 409 | 동일 대상에 대해 이미 신고 접수됨 |

## 코드 예시

### 요청

```json
{
  "targetType": "PLAN",
  "targetId": "27",
  "reasonCode": "FAKE_INFO",
  "detail": "장소 운영시간이 실제와 달라요."
}
```

### 응답

```json
{
  "status": 201,
  "data": {
    "reportId": 88,
    "createdAt": "2026-07-01T14:00:00"
  }
}
```

# REP-3. 코스 신고 (플랜 전용)
## URL : POST /api/plan/{planId}/report

> `CourseViewPage` MoreVertical 메뉴 → 신고하기. REP-2로 통합 가능하나 별도 엔드포인트 존재.

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| reason | String | 필수 | 신고 사유 |
| detail | String | 선택 | 상세 설명 (최대 500자) |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 신고 접수 |
| 400 | 요청 데이터 오류 (reason 누락) |
| 401 | 인증 필요 |
| 404 | 플랜을 찾을 수 없음 |
| 409 | 동일 플랜에 대해 이미 신고 접수됨 |
