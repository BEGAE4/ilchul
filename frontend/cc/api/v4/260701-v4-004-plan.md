# PLAN-1. 플랜 생성
## URL : POST /api/plan

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| title | String | 필수 | 플랜 제목 (최대 50자) |
| description | String | 선택 | 플랜 설명 (최대 500자) |
| isPublic | Boolean | 선택 | 공개 여부 (기본 false) |
| thumbnailUrl | String | 선택 | 썸네일 이미지 URL |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 플랜 생성 성공 |
| 400 | 요청 데이터 오류 |
| 401 | 인증 필요 |

## 코드 예시

### 응답

```json
{
  "status": 201,
  "data": {
    "planId": 27
  }
}
```

# PLAN-3. 플랜 장소 일괄 업데이트
## URL : POST /api/plan-place/{planId}/update

> 코스 편집 화면에서 출발지 + 장소 목록을 한 번에 저장하는 통합 뮤테이션 엔드포인트.
> 기존 개별 CRUD(추가/삭제/순서변경) 대신 이 엔드포인트 단일 호출로 대체.

### 경로 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| planId | Integer | 필수 | 업데이트할 플랜 ID |

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| departurePoint | Object | 선택 | 출발지 정보 (미전달 시 기존값 유지) |
| departurePoint.name | String | 필수(객체 전달 시) | 출발지 장소명 |
| departurePoint.address | String | 필수(객체 전달 시) | 출발지 주소 |
| departurePoint.x | Float | 필수(객체 전달 시) | 출발지 경도 |
| departurePoint.y | Float | 필수(객체 전달 시) | 출발지 위도 |
| places | Array | 필수 | 장소 목록 (빈 배열이면 모든 장소 제거) |
| places[].placeId | Integer | 필수 | 장소 ID |
| places[].order | Integer | 필수 | 순서 (1부터 시작) |
| places[].planPlaceId | Integer | 선택 | 기존 플랜-장소 매핑 ID (신규 추가면 미전달) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 업데이트 성공 |
| 400 | 요청 데이터 오류 (places 누락, order 중복 등) |
| 401 | 인증 필요 |
| 403 | 플랜 소유자가 아님 |
| 404 | planId 또는 places[].placeId 찾을 수 없음 |

## 코드 예시

### 요청

```json
{
  "departurePoint": {
    "name": "성수역 2호선",
    "address": "서울 성동구 성수동1가",
    "x": 127.0567,
    "y": 37.5447
  },
  "places": [
    { "placeId": 165, "order": 1, "planPlaceId": 101 },
    { "placeId": 200, "order": 2 }
  ]
}
```

### 응답

```json
{
  "status": 200,
  "data": {
    "planId": 13
  }
}
```
