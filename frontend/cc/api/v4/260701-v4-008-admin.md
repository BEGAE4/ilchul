# ADM-1. 신고 목록 조회
## URL : GET /api/admin/reports

> BFF: `src/app/api/admin/reports/route.ts`
> 운영자 어드민 화면에서 신고 목록을 조회한다. 상태·대상 유형·사유·키워드 등 복합 필터와 정렬을 지원한다.

### 쿼리 파라미터

| **이름** | **유형** | **필수/선택** | **기본값** | **설명** |
| --- | --- | --- | --- | --- |
| status | String | 선택 | — | `PENDING` / `REVIEWING` / `RESOLVED` / `REJECTED` / `all`. 미지정 시 전체 |
| targetType | String | 선택 | — | `PLAN` / `COMMENT` / `USER` / `all`. 미지정 시 전체 |
| reasonCode | String | 선택 | — | 신고 사유 코드 (REP-1 enum) / `all` |
| q | String | 선택 | — | 키워드 검색 (신고자 닉네임, 사유, 대상 제목 등) |
| page | Integer | 선택 | `1` | 페이지 번호 (1-based) |
| size | Integer | 선택 | `20` | 페이지 크기 (최소 1, 최대 100) |
| sort | String | 선택 | `createdAt:desc` | `createdAt:desc` / `createdAt:asc` / `reportCount:desc` |
| autoBlindedOnly | Boolean | 선택 | `false` | `true` 시 자동 블라인드 처리된 신고만 조회 |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 401 | 인증 필요 |
| 403 | 관리자 권한 없음 |

## 코드 예시

### 응답

```json
{
  "data": [
    {
      "reportId": 10,
      "reasonCode": "ETC",
      "status": "PENDING",
      "reporterId": 4,
      "reporterNickname": "맛집헌터",
      "createdAt": "2026-06-03T15:07:07",
      "updatedAt": "2026-06-09T22:47:57",
      "assignedOperator": null,
      "reportCount": 2,
      "autoBlinded": false,
      "target": {
        "type": "USER",
        "id": 2,
        "ownerId": "힙스터김",
        "title": "힙스터김",
        "contextUrl": "/profile/2"
      }
    }
  ],
  "totalCount": 10,
  "page": 1,
  "size": 20,
  "hasNext": false
}
```

### 응답 필드

| 필드 | 유형 | 설명 |
| --- | --- | --- |
| reportId | Integer | 신고 식별자 |
| target | Object | 신고 대상 (`type`, `id`, `ownerId`, `title`, `contextUrl`) |
| reasonCode | String | 신고 사유 코드 |
| status | String | 처리 상태. `PENDING` / `REVIEWING` / `RESOLVED` / `REJECTED` |
| reporterId | Integer | 신고자 ID |
| reporterNickname | String | 신고자 닉네임 |
| createdAt | String | 신고 접수 시각 (ISO 8601) |
| updatedAt | String | 마지막 상태 변경 시각 |
| assignedOperator | String \| null | 담당 운영자. 미배정 시 null |
| reportCount | Integer | 동일 대상 누적 신고 건수 |
| autoBlinded | Boolean | 자동 블라인드 처리 여부 |

# ADM-2. 신고 상세 조회
## URL : GET /api/admin/reports/{reportId}

> BFF: `src/app/api/admin/reports/[reportId]/route.ts`
> 목록 항목 필드에 더해 신고 상세 텍스트, 처리 이력, 연관 신고 목록을 반환한다.

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 401 | 인증 필요 |
| 403 | 관리자 권한 없음 |
| 404 | 신고를 찾을 수 없음 |

    "title": "홍대 맛집 투어 A to Z",

    {
      "status": "RESOLVED",

### ADM-1 대비 추가 필드

| 필드 | 유형 | 설명 |
| --- | --- | --- |

| relatedReports | Array | 동일 대상 타 신고 요약 목록 |
| resolution | String \| null | 처리 결과. `BLINDED` / `WARNED` / `BANNED` / `NO_ACTION`. 미처리 시 null |

# ADM-3. 신고 상태 변경
## URL : PATCH /api/admin/reports/{reportId}

> BFF: `src/app/api/admin/reports/[reportId]/route.ts`
> 제재 없이 `REVIEWING`(검토 시작) 또는 `REJECTED`(각하) 처리에 사용. 제재 동반 `RESOLVED`는 ADM-4 사용.

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| status | String | 필수 | `REVIEWING` / `REJECTED` 만 허용 |
| note | String | 선택 | 운영자 처리 메모 (history에 기록됨) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 상태 변경 성공. 변경된 `AdminReportDetail` 반환 |
| 400 | 허용되지 않은 status 값 (`PENDING`, `RESOLVED` 등) |
| 401 | 인증 필요 |
| 403 | 관리자 권한 없음 |
| 404 | 신고를 찾을 수 없음 |

## 코드 예시

### 요청

```json
{
  "status": "REVIEWING",
  "note": "자동 블라인드 건 우선 검토"
}
```

### 응답: ADM-2와 동일한 `AdminReportDetail` 구조 반환. `status`와 `histories`가 갱신된 상태.

# ADM-4. 제재 발행
## URL : POST /api/admin/reports/{reportId}/sanctions

> BFF: `src/app/api/admin/reports/[reportId]/sanctions/route.ts`
> 신고를 처리 완료(`RESOLVED`)하고 피신고자에게 제재를 발행한다. 호출 성공 시 신고 `status`가 `RESOLVED`로 자동 변경.

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| reportId | String | 필수 | 경로 파라미터와 동일 (서버 측 일관성 검증용) |
| type | String | 필수 | `WARNING` / `CONTENT_BLINDED` / `TEMP_BAN` / `PERMANENT_BAN` |
| durationDays | Integer | 선택 | 정지 기간(일). `TEMP_BAN` 일 때만 유효 |
| message | String | 필수 | 피신고자에게 노출되는 제재 사유 메시지 |
| resolution | String | 필수 | `BLINDED` / `WARNED` / `BANNED` / `NO_ACTION` |

### 제재 유형 × 처리 결과 권장 조합

| type | 권장 resolution | 설명 |
| --- | --- | --- |
| WARNING | WARNED | 경고만 발행. 콘텐츠 제재 없음 |
| CONTENT_BLINDED | BLINDED | 특정 콘텐츠(플랜/댓글) 숨김 처리 |
| TEMP_BAN | BANNED | 계정 일시 정지. durationDays 필수 |
| PERMANENT_BAN | BANNED | 계정 영구 정지 |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 제재 발행 성공 |
| 400 | 허용되지 않은 type / resolution 값, 또는 message 누락 |
| 401 | 인증 필요 |
| 403 | 관리자 권한 없음 |
| 404 | 신고를 찾을 수 없음 |
| 406 | 이미 처리된 신고 |

## 코드 예시

### 요청 — CONTENT_BLINDED

```json
{
  "reportId": "r-1031",
  "type": "CONTENT_BLINDED",
  "message": "신고 다수 누적으로 해당 플랜이 블라인드 처리되었습니다.",
  "resolution": "BLINDED"
}
```

### 요청 — TEMP_BAN

```json
{
  "reportId": "r-991",
  "type": "TEMP_BAN",
  "durationDays": 7,
  "message": "반복적인 욕설/비방으로 7일간 일시 정지되었습니다.",
  "resolution": "BANNED"
}
```

### 응답

```json
{
  "sanctionId": "s-201",
  "report": {
    "reportId": "r-1031",
    "status": "RESOLVED",
    "resolution": "BLINDED"
  }
}
```
