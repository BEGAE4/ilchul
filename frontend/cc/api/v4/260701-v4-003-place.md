# PLACE-1. 장소 상세 조회
## URL : GET /api/place/{placeId}

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 404 | 장소를 찾을 수 없음 |

```json
    "categoryName": "카페",
    "address": "서울 성동구 아차산로 17길 49",
    "placeImageUrl": "https://example.com/cafe.jpg",

    "isLiked": false,
    "bookmarkCount": 413,
    "isBookmarked": false,
    "rating": 4.5,
    "reviewCount": 128
  }
}
```

# PLACE-4. 장소 좋아요
## URL : POST /api/place/like/{placeId}

> `PlaceDetailPage` Heart 버튼 토글 시 호출 (이미 좋아요 상태면 DELETE).

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 400 | 요청 데이터 오류 (placeId 형식 오류) |
| 401 | 인증 필요 |
| 404 | 장소를 찾을 수 없음 |
| 409 | 이미 좋아요 처리됨 (POST) / 좋아요 상태가 아님 (DELETE) |

## 코드 예시

### 응답

```json
{
  "status": 200,
  "data": {
    "placeId": 165,
    "isLiked": true,
    "likeCount": 2341
  }
}
```
