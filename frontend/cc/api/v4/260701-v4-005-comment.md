# CMT-1. 댓글 목록 조회
## URL : GET /api/reply/{planId}

> 커서 기반 페이지네이션. `useComments` 훅에서 `lastReplyId` 파라미터로 무한 스크롤 구현.

### 쿼리 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| lastReplyId | Integer | 선택 | 마지막으로 받은 댓글 ID (처음 조회면 미전달) |
| size | Integer | 선택 | 조회 개수 (기본 20) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 404 | 플랜을 찾을 수 없음 |

## 코드 예시

### 응답

```json
{
  "status": 200,
  "data": {
    "replies": [
      {
        "replyId": 1,
        "content": "정말 좋은 코스네요!",
        "author": {
          "userId": 4,
          "nickname": "맛집헌터",
          "profileImageUrl": "https://example.com/profile.jpg"
        },
        "likeCount": 5,
        "isLiked": false,
        "childCount": 2,
        "children": [],
        "createdAt": "2026-06-10T14:00:00",
        "updatedAt": "2026-06-10T14:00:00",
        "isDeleted": false
      }
    ],
    "hasNext": true,
    "lastReplyId": 1
  }
}
```

# CMT-2. 댓글 작성
## URL : POST /api/reply/{planId}

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| content | String | 필수 | 댓글 내용 (최대 500자) |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 댓글 작성 성공 |
| 400 | content 누락 또는 빈 문자열 |
| 401 | 인증 필요 |
| 404 | 플랜을 찾을 수 없음 |

## 코드 예시

### 요청

```json
{
  "content": "정말 좋은 코스네요!"
}
```

### 응답

```json
{
  "status": 201,
  "data": {
    "replyId": 10,
    "content": "정말 좋은 코스네요!",
    "author": {
      "userId": 4,
      "nickname": "맛집헌터",
      "profileImageUrl": "https://example.com/profile.jpg"
    },
    "likeCount": 0,
    "isLiked": false,
    "childCount": 0,
    "children": [],
    "createdAt": "2026-07-01T14:00:00",
    "isDeleted": false
  }
}
```

# CMT-5. 대댓글 작성
## URL : POST /api/reply/{planId}/{replyId}

> `replyId`가 부모 댓글 ID. 1단계 중첩만 지원(대댓글의 대댓글 불가).

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| content | String | 필수 | 대댓글 내용 (최대 500자) |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 대댓글 작성 성공 |
| 400 | content 누락 또는 대댓글에 재귀 중첩 시도 |
| 401 | 인증 필요 |
| 404 | 부모 댓글을 찾을 수 없음 |

---

# CMT-6. 댓글 좋아요
## URL : POST /api/reply/{planId}/{replyId}/like

> 이미 좋아요 상태면 DELETE로 취소.

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 401 | 인증 필요 |
| 404 | 댓글을 찾을 수 없음 |
| 409 | 이미 좋아요 처리됨 (POST) / 좋아요 상태가 아님 (DELETE) |

# CMT-7. 댓글 신고
## URL : POST /api/reply/{planId}/{replyId}/report

> REPORT API(REP-2)의 `targetType: COMMENT` 사용과 별개로 존재하는 댓글 전용 엔드포인트.

### 본문 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| reason | String | 필수 | 신고 사유 |
| detail | String | 선택 | 상세 설명 (최대 500자) |

### 응답 코드

| status | message |
| --- | --- |
| 201 | 신고 접수 |
| 400 | reason 누락 |
| 401 | 인증 필요 |
| 404 | 댓글을 찾을 수 없음 |
| 409 | 동일 댓글에 대해 이미 신고 접수됨 |
