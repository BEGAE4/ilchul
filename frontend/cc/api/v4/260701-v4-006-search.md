# SEARCH-1. 통합 검색 (장소 + 코스)
## URL : GET /api/search

### 쿼리 파라미터

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| keyword | String | 필수 | 검색어 |
| type | String | 선택 | `place` / `plan` / 미지정 시 전체 |
| page | Integer | 선택 | 페이지 번호 (기본 1) |
| size | Integer | 선택 | 페이지 크기 (기본 20) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 400 | keyword 누락 |

## 코드 예시

### 응답

```json
{
  "status": 200,
  "data": {
    "places": [
      {
        "placeId": 165,
        "placeName": "블루보틀 성수",
        "address": "서울 성동구 아차산로 17길 49",
        "categoryName": "카페",
        "placeImageUrl": "https://example.com/cafe.jpg"
      }
    ],
    "plans": [
      {
        "planId": 27,
        "planTitle": "성수동 힙플레이스 완전 정복",
        "thumbnailUrl": "https://example.com/thumb.jpg",
        "location": "서울 성동구",
        "likeCount": 124
      }
    ],
    "hasNext": false
  }
}
```
