# USER-1. 사용자 프로필 수정
## URL : PATCH /api/mypage/nickname | /api/mypage/profile

> 마이페이지에서 닉네임 / 프로필 이미지 수정 시 호출.

### 본문 파라미터 (닉네임)

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| nickname | String | 필수 | 변경할 닉네임 |

### 본문 파라미터 (프로필 이미지)

| **이름** | **유형** | **필수/선택** | **설명** |
| --- | --- | --- | --- |
| profileImage | File | 필수 | 업로드할 이미지 (multipart/form-data) |

### 응답 코드

| status | message |
| --- | --- |
| 200 | 성공 |
| 400 | 요청 데이터 오류 |
| 401 | 인증 필요 |
| 404 | 회원을 찾을 수 없습니다. |
| 409 | 이미 사용 중인 닉네임 |
