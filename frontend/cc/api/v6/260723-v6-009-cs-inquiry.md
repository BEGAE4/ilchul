# v6 — 고객 문의 API

> 태그: 고객 문의 — 작성, 수정, 삭제, 조회 및 답변

## 공통 enum

```ts
type InquiryType = 'GENERAL' | 'BUG' | 'SUGGESTION' | 'OTHER';
type InquiryStatus = 'OPEN' | 'IN_PROGRESS' | 'RESOLVED' | 'CLOSED';
```

## POST /api/cs-inquiry — 문의 작성

- 파라미터: `request` (query, `CreateCsInquiryRequestDto`) ※ swagger상 query 정의이나 이미지 포함이므로 실제로는 multipart 전송으로 추정

```ts
interface CreateCsInquiryRequestDto {
  title: string;          // minLength 1
  content: string;        // minLength 1
  inquiryType: InquiryType; // 필수
  images?: File[];        // binary
}
```

- 응답 `201`: `CreateCsInquiryResponseDto` — `{ inquiryId, title, inquiryType, inquiryStatus, createdAt }`

## GET /api/cs-inquiry/my — 내 문의 목록 조회

- query: `size` (int, 기본 10, 최소 1), `lastInquiryId` (int, 커서)
- 응답 `200`: `UserCsInquiryListResponseDto`

```ts
interface UserCsInquiryListResponseDto {
  items: {
    inquiryId: number;
    title: string;
    inquiryType: InquiryType;
    inquiryStatus: InquiryStatus;
    hasAnswer: boolean;
    createdAt: string;
  }[];
  nextCursorId: number;
  hasNext: boolean;
}
```

## GET /api/cs-inquiry/category — 카테고리 목록 조회

- 응답 `200`: `InquiryTypeListResponseDto` — `{ categories: { slug: string; name: string }[] }`

## PATCH /api/cs-inquiry/{inquiryId} — 문의 수정 (작성자 본인)

- 파라미터: `request` (query, `UpdateCsInquiryRequestDto`)

```ts
interface UpdateCsInquiryRequestDto {
  title: string;
  content: string;
  inquiryType: InquiryType;  // 필수
  newImages?: File[];
  deleteImageIds?: number[];
}
```

- 응답 `200`: `UpdateCsInquiryResponseDto` — `{ inquiryId, title, content, inquiryType, inquiryStatus, updatedAt }`

## DELETE /api/cs-inquiry/{inquiryId} — 문의 삭제 (작성자 본인)

- 응답 `200`: `object`

## PATCH /api/cs-inquiry/{inquiryId}/close — 문의 종료 (완료 처리)

작성자가 문의가 해결되었음을 확인하고 종료.

- 응답: `200 OK`

# 관리자 API

## GET /api/cs-inquiry — 문의사항 목록 조회 (관리자)

- query: `category` (`InquiryType`), `search` (string, 제목/내용 키워드), `size` (int, 기본 10), `lastInquiryId` (int, 커서)
- 응답 `200`: `AdminCsInquiryListResponseDto`

```ts
interface AdminCsInquiryListResponseDto {
  items: {
    inquiryId: number;
    title: string;
    inquiryType: InquiryType;
    inquiryStatus: InquiryStatus;
    hasAnswer: boolean;
    authorNickname: string;
    createdAt: string;
  }[];
  nextCursorId: number;
  hasNext: boolean;
  totalCount: number; // int64
}
```

## POST /api/cs-inquiry/{inquiryId}/reply — 답변 작성 (관리자)

- 요청 body: `ReplyCsInquiryRequestDto` — `{ content: string /* minLength 1 */ }`
- 응답 `200`: `ReplyCsInquiryResponseDto` — `{ answerId, inquiryId, content, answeredBy, answeredAt }`
