# v6 — 마이페이지 API

> 태그: 마이페이지

## GET /api/mypage/profile — 프로필 조회

- 응답 `200`: `UserProfileResponseDto`

```ts
interface UserProfileResponseDto {
  userNickname: string;
  userImg: string;
  userIntro: string;
}
```

## PATCH /api/mypage/profile — 프로필 수정

- 요청 body: `UpdateUserProfileRequest`

```ts
interface UpdateUserProfileRequest {
  newUserNickname?: string;
  newUserIntro?: string;
  newUserProfileImg?: string;
}
```

- 응답 `202 Accepted`: `UserProfileResponseDto` (수정 후 프로필)

## GET /api/mypage/summary — 활동 요약 조회

- 응답 `200`: `UserProfileSummaryResponseDto`

```ts
interface UserProfileSummaryResponseDto {
  publicPlanCount: number;       // 공개 플랜 수
  verifyPlanCount: number;       // 인증 플랜 수
  scrappedByOthersCount: number; // 남이 스크랩한 수
  savedCourseCount: number;      // 저장한 코스 수
}
```

## GET /api/mypage/scrapped — 스크랩한 플랜 목록

- 응답 `200`: `ScrappedPlanResponseDto`

```ts
interface ScrappedPlanResponseDto {
  scrappedPlans: ScrappedPlanSummary[];
}
interface ScrappedPlanSummary {
  planId: number;
  planTitle: string;
  createAt: string;        // date-time
  tripStartDate: string;   // date-time
  tripEndDate: string;     // date-time
  isPlanVisible: boolean;
  requiredTime: number;
  planImages: string[];
}
```

## GET /api/mypage/plans — 내 플랜 목록

- 응답 `200`: `MyPlansResponse` / `204`: 조회된 플랜 없음

```ts
interface MyPlansResponse {
  plans: PlanSummary[];
}
// PlanSummary는 ScrappedPlanSummary와 동일 필드 구성
```

## POST /api/mypage/plan/visibility/{planId} — 플랜 공개 여부 토글

- path: `planId` (int)
- 응답: `200` 변경 성공 / `304 Not Modified` 변경되지 않음
