# v6 — 플랜 장소 API

> 태그: 플랜 장소 — 미리보기, 수정 및 인증 스탬프

## POST /api/plan-place/preview — 플랜 생성 전 미리보기

선택한 장소들을 기반으로 경로 및 소요 정보를 미리 계산.

- 요청 body: `CreatePlanPreviewRequestDto`

```ts
interface CreatePlanPreviewRequestDto {
  planTitle: string;
  planDescription: string;
  isPlanVisible: boolean;
  departurePoint: DeparturePointDto; // { name, address, x, y }
  tripStartDate: string; // date-time
  tripEndDate: string;   // date-time
  places: { placeId: number; order: number }[];
}
```

- 응답 `200`: `CreatePlanPreviewResponseDto`

```ts
interface CreatePlanPreviewResponseDto {
  planTitle: string;
  planDescription: string;
  isPlanVisible: boolean;
  requiredTime: number;
  totalDistance: number;
  departurePoint: DeparturePointDto;
  tripStartDate: string;
  tripEndDate: string;
  places: PlanPlacePreview[];
}
interface PlanPlacePreview {
  placeId: number;
  placeName: string;
  addressName: string;
  roadAddressName: string;
  categoryName: string;
  duration: number;  // 이동 시간
  order: number;
  stayTime: number;
  isStamped: boolean;
  x: number;
  y: number;
}
```

## POST /api/plan-place/{planId}/preview — 플랜 수정 미리보기

- path: `planId` (int)
- 요청 body: `UpdatePlanPlaceRequestDto` (아래와 동일)
- 응답 `200`: `UpdatePlanPreviewResponseDto` — `CreatePlanPreviewResponseDto`에 `planId` 필드 추가된 형태

## POST /api/plan-place/{planId}/update — 플랜 장소 수정

기존 플랜의 장소 목록 및 순서 정보 수정.

- 요청 body: `UpdatePlanPlaceRequestDto`

```ts
interface UpdatePlanPlaceRequestDto {
  departurePoint: DeparturePointDto;
  places: {
    planPlaceId: number; // 기존 장소면 기존 ID, 신규면 없음(추정)
    placeId: number;
    order: number;
  }[];
}
```

- 응답 `200`: `UpdatePlanPlaceResponseDto` — `{ planId }`

## POST /api/plan-place/{planPlaceId}/stamp — 방문 인증 스탬프 등록

- path: `planPlaceId` (int)
- 요청 body: `multipart/form-data` — `StampPlanPlaceRequestDto`

```ts
interface StampPlanPlaceRequestDto {
  image: File;                          // binary
  location: { x: number; y: number };   // 현재 위치
}
```

- 응답 `200`: `StampPlanPlaceResponseDto`

```ts
interface StampPlanPlaceResponseDto {
  planPlaceId: number;
  isStamped: boolean;
  verifiedImage: string;
  stampedAt: string; // date-time
}
```
