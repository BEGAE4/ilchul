# v6 — 장소 API

> 태그: 장소 — 조회, 추천, 좋아요, 스크랩 및 후기

## GET /api/place/{placeId} — 장소 상세 조회

- path: `placeId` (int)
- 응답 `200`: `PlaceDetailResponseDto`

```ts
interface PlaceDetailResponseDto {
  placeId: number;
  placeName: string;
  addressName: string;
  roadAddressName: string;
  categoryName: string;
  phone: string;
  placeUrl: string;
  placeImageUrl: string;
  x: number; // 경도
  y: number; // 위도
}
```

## GET /api/place/{placeId}/plan — 장소가 포함된 코스 조회

특정 장소가 포함된 공개 코스 목록.

- 응답 `200`: `PopularPlanItemDto[]`

```ts
interface PopularPlanItemDto {
  id: number;
  title: string;
  description: string;
  thumbnail: string;
  location: string;
  duration: string;
  likes: number;
  ranking: number;
}
```

## GET /api/place/search — 장소 검색

- query: `keyword` (string, 필수, 예: "카페")
- 응답 `200`: `SearchPlaceResponseDto[]`

```ts
interface SearchPlaceResponseDto {
  placeId: number;
  placeImageUrl: string;
  categoryName: string;
  placeName: string;
  x: number;
  y: number;
}
```

## GET /api/place/popular — 내 주변 인기 장소

- query: `lat` (double, 필수), `lng` (double, 필수), `limit` (int, 기본 5), `page` (int, 기본 1)
- 응답 `200`: `PopularPlaceResponseDto`

## GET /api/place/popular/nationwide — 전국 인기 장소

- query: `limit` (int, 기본 6), `page` (int, 기본 1)
- 응답 `200`: `PopularPlaceResponseDto`

```ts
interface PopularPlaceResponseDto {
  status: number;
  message: string;
  data: PopularPlaceItemDto[];
  page: number;
  limit: number;
  hasNext: boolean;
  totalCount: number;
}
interface PopularPlaceItemDto {
  id: number;
  name: string;
  category: string;
  location: string;
  image: string;
  ranking: number;
}
```

## POST /api/place/recommend — 장소 추천 (설문 기반)

- 요청 body: `SurveyResultDto`

```ts
interface SurveyResultDto {
  emotion: string;
  startTime: string;
  endTime: string;
  transport: string;
  location: { x: number; y: number };
}
```

- 응답 `200`: `object` (스키마 미정의)

## POST /api/place/{placeId}/likes — 좋아요 등록
## DELETE /api/place/{placeId}/likes — 좋아요 취소

- 응답 `200`: `LikeResponseDto`

interface LikeResponseDto {

## GET /api/place/{placeId}/review — 후기 목록 조회 (비로그인 가능)

- query: `lastReviewId` (int, 커서), `limit` (int, 기본 10)
- 응답 `200`: `PlaceReviewListResponseDto`

```ts
interface PlaceReviewListResponseDto {
  status: number;
  message: string;
  data: PlaceReviewResponseDto[];
  hasNext: boolean;
}
```

## POST /api/place/{placeId}/review — 후기 작성

- 요청 body: `PlaceReviewRequestDto` — `{ content: string }` (최대 1000자)
- 응답 `201`: `PlaceReviewResponseDto`

```ts
interface PlaceReviewResponseDto {
  reviewId: number;
  userId: number;
  userNickname: string;
  userImg: string;
  content: string;
  createAt: string; // date-time
}
```
