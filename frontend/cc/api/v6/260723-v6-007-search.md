# v6 — 최근 검색어 API

> 태그: 최근 검색어 — 조회, 저장 및 삭제 (로그인 필요)

## GET /api/recent — 최근 검색어 조회

- 응답 `200`: `SearchLog[]`

```ts
interface SearchLog {
  name: string;      // 검색어
  createdAt: string;
}
```

## POST /api/recent — 최근 검색어 저장

- 요청 body: `SearchLogSaveRequest` — `{ name: string }`
- 응답: `200 OK`

## DELETE /api/recent — 최근 검색어 삭제

- 요청 body: `SearchLogDeleteRequest` — `{ name: string; createdAt: string }`
- 응답: `204 No Content`
- ※ DELETE 요청에 body가 필요함에 유의 (axios: `axios.delete(url, { data })`)
