# v6 — 플랜 API (플랜 / 좋아요 / 플랜 스크랩)

> 태그: 플랜, 좋아요, 플랜 스크랩

## POST /api/plan/create — 플랜 생성

- 요청 body: `CreatePlanRequestDto`

```ts
interface CreatePlanRequestDto {
  planTitle: string;
  isPlanVisible: boolean;
  planDescription: string;
  requiredTime: number;    // 분
  totalDistance: number;   // m
  departurePoint: DeparturePointDto;
  tripStartDate: string;   // date-time
  tripEndDate: string;     // date-time
  places: CreatePlanPlaceRequest[];
}
interface DeparturePointDto {
  name: string;
  address: string;
  x: number;
  y: number;
}
interface CreatePlanPlaceRequest {
  placeId: number;
  order: number;
  travelTime: number;
  stayTime: number;
}
```

- 응답 `201`: `CreatePlanResponseDto` — `{ planId, planTitle, createAt, planVisible }`

## PATCH /api/plan/{planId} — 플랜 수정

기본 정보 및 수정 가능한 여행 정보 변경 (장소 수정은 plan-place API 사용).

- 요청 body: `UpdatePlanRequestDto` — `{ planTitle?, isPlanVisible?, planDescription?, tripStartDate?, tripEndDate? }`
- 응답 `200`: `UpdatePlanResponseDto` — `{ planId }`

## DELETE /api/plan/{planId} — 플랜 삭제

- 응답: `204 No Content`

## POST /api/plan/{planId}/clone — 플랜 복제

원본 플랜을 복제해 내 플랜으로 새로 생성.

- 요청 body: `PlanCopyRequestDto` — `{ scheduledDate: string /* date */ }`
- 응답 `201`: `PlanCopyResponseDto` — `{ planId, originalPlanId, createAt }`

## POST /api/plan/{planId}/images — 이미지 업로드

- query: `images` (binary[], 필수) ※ swagger상 query로 정의되어 있으나 실제로는 multipart 업로드로 추정
- 응답 `200`: `PlanDetailDto`

## DELETE /api/plan/{planId}/images — 이미지 삭제

- query: `imageIds` (int[], 필수)
- 응답 `200`: `PlanDetailDto`

## GET /api/plan/popular — 내 주변 인기 플랜

- query: `lat` (double, 필수), `lng` (double, 필수), `limit` (int, 기본 5), `page` (int, 기본 1)
- 응답 `200`: `PopularPlanResponseDto`

## GET /api/plan/popular/nationwide — 전국 인기 플랜

- query: `limit` (int, 기본 3), `page` (int, 기본 1)
- 응답 `200`: `PopularPlanResponseDto`

```ts
interface PopularPlanResponseDto {
  status: number;
  message: string;
  data: PopularPlanItemDto[];
  page: number;
  limit: number;
  hasNext: boolean;
  totalCount: number;
}
interface PopularPlanItemDto {
  id: number;
  title: string;
  description: string;
  thumbnail: string;
  location: string;
  duration: string;
  likes: number;
  ranking: number;
}
```
