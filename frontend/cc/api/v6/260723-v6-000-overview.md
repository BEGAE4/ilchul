## 엔드포인트 전체 목록 (총 46개)

### 인증 (4)
- `POST /api/sign/logout` — 로그아웃
- `GET /api/sign/userinfo` — 사용자 정보 조회
- `GET /api/sign/reissue` — 토큰 재발급
- `DELETE /api/sign/delete` — 회원 탈퇴

### 마이페이지 (6)
- `GET /api/mypage/profile` / `PATCH /api/mypage/profile` — 프로필 조회/수정
- `GET /api/mypage/summary` — 활동 요약
- `GET /api/mypage/scrapped` — 스크랩한 플랜 목록
- `GET /api/mypage/plans` — 내 플랜 목록
- `POST /api/mypage/plan/visibility/{planId}` — 플랜 공개 여부 토글

### 장소 (11)
- `GET /api/place/{placeId}` — 상세 조회

- `POST /api/place/recommend` — 설문 기반 추천
- `POST/DELETE /api/place/{placeId}/likes` — 좋아요 등록/취소
- `POST/DELETE /api/place/{placeId}/scraps` — 스크랩 추가/취소
- `GET/POST /api/place/{placeId}/review` — 후기 조회/작성

### 플랜 (10)
- `POST /api/plan/create` — 생성

- `POST/DELETE /api/plan/{planId}/images` — 이미지 업로드/삭제
- `GET /api/plan/popular` / `GET /api/plan/popular/nationwide` — 인기 플랜
- `POST/DELETE /api/like/{planId}` — 플랜 좋아요 등록/취소
- `POST /api/plan/scrapped/{planId}` — 플랜 스크랩 등록

- `POST /api/plan-place/{planId}/update` — 장소 목록/순서 수정

## 공통 사항

- **페이징**: 대부분 커서 기반(`lastXxxId` + `size`/`limit`, 응답에 `hasNext`). 인기 플랜/장소는 페이지 번호 기반(`page` + `limit`, 응답에 `totalCount`, `hasNext`).
- **비로그인 허용**: 댓글/대댓글 목록 조회, 장소 후기 목록 조회는 비로그인 사용 가능 명시.
- **응답 wrapper**: 인기 플랜/장소, 후기 목록은 `{status, message, data, ...}` wrapper 형태. 나머지는 DTO 직접 반환.
- **enum 공통값**
  - 신고 대상: `PLAN | REPLY | USER`
  - 신고 사유: `SPAM_AD | FAKE_INFO | OBSCENE | ABUSE | COPYRIGHT | IMPROPER_PROFILE | IMPERSONATION | PERSONAL_INFO_LEAK | ETC`
  - 신고 상태: `PENDING | REVIEWING | RESOLVED | REJECTED`
  - 문의 유형: `GENERAL | BUG | SUGGESTION | OTHER`
  - 문의 상태: `OPEN | IN_PROGRESS | RESOLVED | CLOSED`
