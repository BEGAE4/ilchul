# v6 — 인증 API

> 태그: 인증 — 사용자 인증, 로그아웃, 토큰 재발급 및 회원 탈퇴

## POST /api/sign/logout — 로그아웃

리프레시 토큰을 삭제하고 인증 정보를 만료 처리.

- 요청: 없음
- 응답: `204 No Content`

## GET /api/sign/userinfo — 사용자 정보 조회

현재 로그인한 사용자의 이메일과 권한 정보를 조회.

- 응답: `200` — `object` (스키마 미정의, 이메일/권한 포함)

## GET /api/sign/reissue — 토큰 재발급

리프레시 토큰 기반으로 액세스 토큰 재발급.

- 응답: `200` — `string` (새 액세스 토큰)

## DELETE /api/sign/delete — 회원 탈퇴

- 응답: `200 OK` (summary/description 미기재)

## 비고

- OAuth 로그인 엔드포인트는 swagger에 노출되지 않음 (Spring Security 처리 추정).
- 전역 security: JWT Bearer (`jwtAuth`).
