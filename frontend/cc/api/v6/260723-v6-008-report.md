# v6 — 신고 API (사용자 / 관리자)

> 태그: 신고, 신고 관리(관리자)

## 공통 enum

```ts
type ReportTargetType = 'PLAN' | 'REPLY' | 'USER';
type ReportReasonCode =
  | 'SPAM_AD' | 'FAKE_INFO' | 'OBSCENE' | 'ABUSE' | 'COPYRIGHT'
  | 'IMPROPER_PROFILE' | 'IMPERSONATION' | 'PERSONAL_INFO_LEAK' | 'ETC';
type ReportStatus = 'PENDING' | 'REVIEWING' | 'RESOLVED' | 'REJECTED';
type SanctionType = 'CONTENT_BLINDED' | 'WARNING' | 'PERMANENT_BAN' | 'TEMP_BAN';
type Resolution = 'BLINDED' | 'WARNED' | 'BANNED' | 'NO_ACTION';
```

## POST /api/report — 신고 생성

- 요청 body: `CreateReportRequestDto`

```ts
interface CreateReportRequestDto {
  targetType: ReportTargetType; // 필수
  targetId: number;             // 필수
  reasonCode: ReportReasonCode; // 필수
  detail?: string;
}
```

- 응답 `201`: `CreateReportResponseDto`

```ts
interface CreateReportResponseDto {
  reportId: number;
  reportType: ReportTargetType;
  status: ReportStatus;
  alreadyReported: boolean; // 중복 신고 여부
  isAutoBlinded: boolean;   // 자동 블라인드 처리 여부
}
```

## GET /api/report/reason — 신고 사유 목록 조회

- query: `type` (`PLAN | REPLY | USER`, 필수)
- 응답 `200`: `ReportReasonResponseDto`

```ts
interface ReportReasonResponseDto {
  reportType: ReportTargetType;
  reasonItems: {
    code: string;
    label: string;
    requiresContent: boolean; // 상세 내용 입력 필수 여부
  }[];
}
```

# 관리자 API

## GET /api/admin/reports — 신고 목록 조회

- query: `AdminReportRequestDto` (object 파라미터)

```ts
interface AdminReportRequestDto {
  status?: ReportStatus;
  targetType?: ReportTargetType;
  reasonCode?: ReportReasonCode;
  q?: string;               // 검색 키워드
  page?: number;            // >= 1
  size?: number;            // 1~100
  sort?: 'CREATED_DESC' | 'CREATED_ASC' | 'REPORT_COUNT_DESC';
  autoBlindedOnly?: boolean;
}
```

- 응답 `200`: `AdminReportResponseDto` — `{ data: AdminReportItem[], totalCount, page, size, hasNext }`

## GET /api/admin/reports/{reportId} — 신고 상세 조회

- 응답 `200`: `AdminReportDetailResponseDto`

```ts
interface AdminReportDetailResponseDto {
  reportId: number;
  resolution: Resolution;
  reasonCode: ReportReasonCode;
  status: ReportStatus;
  reporterId: number;
  reporterNickname: string;
  createdAt: string;
  updatedAt: string;
  assignedOperator: number;
  reportCount: number;
  autoBlinded: boolean;
  detail: string;
  target: {
    type: ReportTargetType;
    id: number;
    ownerId: string;
    title: string;
    contextUrl: string;
  };
  histories: { status: ReportStatus; at: string; actor: string; note: string }[];
  relatedReports: { reportId: number; reasonCode: ReportReasonCode; reporterNickname: string; createdAt: string }[];
}
```

## PATCH /api/admin/reports/{reportId} — 신고 상태 변경

- 요청 body: `AdminReportStatusChangeRequestDto` — `{ status: ReportStatus; note?: string }`
- 응답 `200`: `AdminReportDetailResponseDto`

## POST /api/admin/reports/{reportId}/sanctions — 제재 등록

- 요청 body: `AdminReportSanctionRequestDto`

```ts
interface AdminReportSanctionRequestDto {
  type: SanctionType;       // 필수
  durationDays?: number;    // TEMP_BAN 시
  message: string;          // minLength 1
  resolution: Resolution;   // 필수
}
```

- 응답 `200`: `AdminReportSanctionResponseDto` — `{ sanctionId, adminReportDetailResponseDto }`
