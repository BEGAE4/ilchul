# v6 — 댓글 API

> 태그: 댓글 — 플랜 댓글 작성, 수정, 삭제, 조회 및 좋아요

## GET /api/reply/{planId} — 댓글 목록 조회 (비로그인 가능)

- path: `planId` (int)
- query: `size` (int, 기본 10), `lastReplyId` (int, 커서)
- 응답 `200`: `ReplyListResponse`

```ts
interface ReplyListResponse {
  replies: ReplyResponse[];
  hasNext: boolean;
}
interface ReplyResponse {
  replyId: number;
  parentReplyId: number;
  user: string;          // 닉네임
  userId: number;
  avatar: string;
  content: string;
  mentions: { userId: number; userNickname: string }[];
  createdAt: string;     // date-time
  likeCount: number;
  isLiked: boolean;
  replyCount: number;    // 대댓글 수
  isDeleted: boolean;
  replies: ReplyListResponse; // 중첩 대댓글
}
```

## GET /api/reply/{parentReplyId}/children — 대댓글 목록 조회 (비로그인 가능)

- path: `parentReplyId` (int)
- query: `size` (int, 기본 10), `lastReplyId` (int, 커서)
- 응답 `200`: `ReplyListResponse`

## POST /api/reply/{planId} — 댓글 작성

- 요청 body: `CreateReplyRequestDto`

```ts
interface CreateReplyRequestDto {
  content: string;
  parentReplyId?: number; // 대댓글일 경우
  mentions?: number[];    // 멘션 대상 userId 목록
}
```

- 응답 `201`: `number` (생성된 댓글 ID)

## PATCH /api/reply/{replyId} — 댓글 수정

- 요청 body: `PatchReplyRequestDto` — `{ content: string; mentions?: number[] }`
- 응답 `200`: `number` (수정된 댓글 ID)

## DELETE /api/reply/{replyId} — 댓글 삭제

- 응답 `200`: `number` (삭제된 댓글 ID)
